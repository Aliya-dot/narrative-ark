02

每一份安装包，
都可以被验证。

  1. 下载从官方 Release 获取安装包与校验清单。
  2. 计算在 PowerShell 运行 Get-FileHash 文件路径 -Algorithm SHA256。
  3. 比对确认摘要与 Release 中的 manifest 或 SHA256SUMS 一致。
